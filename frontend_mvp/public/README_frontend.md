# Ativos do Frontend - MFS Dashboard

Esta pasta contém os recursos estáticos servidos pelo motor do Dashboard.

### Conteúdo
- Logos oficiais e ativos visuais.
- Configurações de PWA e Favicons.

### Deploy & Produção
O frontend do Motor ForeSig está integrado ao backend e servido via **Google Cloud Run**.

- **URL de Produção:** [https://mfs-backend-564952987470.us-central1.run.app](https://mfs-backend-564952987470.us-central1.run.app)
- **Tecnologias:** React + Vite + TailwindCSS.
- **Integração:** Consome a API REST via endpoints `/v1/*`.
